# Loader

`'use client'` loading indicator.

## Props

| Prop | Default |
|------|---------|
| `label` | `'Loading Data...'` |
| `color` | `'white'` |

Falsy `label` suppresses paragraph (still renders spinner).

## Test ids

`ScaleLoader` uses `LOADER_SELECTORS.LOADER` from `src/lib/test-selectors`.

## Export

Default function component.
