# LogicToggle

Props: `currentLogic` (`AND` \| `OR`), `onToggle`, optional `allTitle` / `anyTitle` tooltips, `className`, `disabled`.

Two-segment button group (`ALL` / `ANY`) with active state styling in `LogicToggle.css`. Ignores clicks when disabled or already selected.
