# HomeHubMinecraftBand

Section titled from `ll.home.minecraftBand` listing projects returned by `listHomeMinecraftProjects()` (excludes IDs already featured in the main hub).

Each row shows title, audience line (`productMarketingAudienceLine`), primary CTA (`getHomeProductPrimaryLink`), and optional “more” link from `getHomeHubMinecraftMoreLink`. Returns `null` when there are no eligible projects.
