# SmartSkeletonLoader

Extended skeleton module duplicating base primitives (`SkeletonText`, `SkeletonBox`, `SkeletonCircle`) plus `useSmartSkeleton` and `SmartSkeletonLoader` with additional layout heuristics for multi-column and nested containers.

Default export: `SmartSkeletonLoader`. Used when captured measurements should drive placeholder geometry.
