# projectShowcaseCatalog

Exports `ProjectShowcaseCategoryId` union (`All`, `Minecraft`, `Streaming`, `Infrastructure`, `Gaming`, `Web Tools`, `Social`), `ProjectShowcaseCategoryOption` (id, label, Lucide icon), and `PROJECT_SHOWCASE_CATEGORY_OPTIONS` array for filter UI.

`PROJECT_SHOWCASE_TOTAL_COUNT` documents expected portfolio size (20).
