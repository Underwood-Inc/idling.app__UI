# RadioPlayerOverflowText

Props: `text`, optional `className`, `as` (`span`|`p`), `title`, `suppressNativeTitle`, `pauseScroll`, `marqueeEnabled` (default true). Measures overflow; applies CSS marquee (`--overflow-distance`, `--overflow-duration`) at 28px/s when text exceeds container.
