# RadioPlayerTrackTitleTip

Props: `trackDisplay`, optional `className`, `marqueeEnabled` (default true). Hover/focus opens portaled tooltip with `resolveRadioPlayerTrackTitleTipPosition` + `RadioPlayerOverflowText` for long ICY titles.

Uses `formatRadioTrackTitleTriggerAria` for trigger a11y.
