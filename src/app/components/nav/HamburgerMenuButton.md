# HamburgerMenuButton

Props: `isOpen`, `onClick`, optional `ariaLabel` (default “Toggle mobile menu”), optional `className`. Sets `aria-expanded` to match `isOpen`; toggles `hamburger-menu-button--open` for CSS animation.
