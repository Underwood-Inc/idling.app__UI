# Card

## Props

| Prop | Default |
|------|---------|
| `width` | `'md'` — `full \| lg \| md \| sm \| min` (`CardPropsWidth`) |
| `className` | optional |
| `height` | optional rem height (inline style; marked for deprecation in source) |
| `children` | required |

Renders `div.card.{width}` with `CARD_SELECTORS.CONTAINER`.

Named export `Card` (not default).
