# OrganicPatternGenerator

## `generateOrganicPattern(layerType, ...)`

Sub-styles by `layerType`:

- polygons (random-sided)
- grid
- blobs
- waves

Appends SVG primitives to shared `patterns` array; updates `colorUsage` where applicable.
