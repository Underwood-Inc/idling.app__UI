# media-domains

Canonical domain lists and helpers for URL validation.

## Constants

`YOUTUBE_DOMAINS`, `MULTI_MEDIA_DOMAINS`, `IMAGE_ONLY_DOMAINS`, `IMAGE_DOMAINS` (combined).

## Helpers (see source)

`isYouTubeDomain`, `isImageDomain`, `hasImageExtension`, domain normalization used by `url-pills` and image parser allowlists.
