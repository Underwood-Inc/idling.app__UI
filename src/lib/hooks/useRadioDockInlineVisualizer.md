# useRadioDockInlineVisualizer

`RADIO_DOCK_INLINE_VIZ_MAX_WIDTH_PX` = **860**.

`useRadioDockInlineVisualizer()` returns boolean — `true` when `window.innerWidth` allows inline visualizer beside dock controls (resize listener).
