# cursorCalculations

Caret placement inside wrapped lines and pill tokens.

Exports include `calculateLineAwareCursorPosition`, `calculateCursorWithinToken`, `calculateCursorPositionWithRange`, text-node walkers (`getTextNodesInElement`, `getFirstTextNode`), `calculateEndOfContentPosition`, and `fallbackCursorPosition`.
