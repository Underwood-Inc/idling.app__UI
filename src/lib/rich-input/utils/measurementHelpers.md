# measurementHelpers

- **`getAccurateCharWidth`** — Probe average glyph width in the editor font.
- **`measureTokenWidthAccurate`** — Width of a rendered token node.
- **`getVisualTextForToken`** — Display string used for measurement (pills vs raw).

Feeds `WidthMeasurement` and enhanced positioning utilities.
