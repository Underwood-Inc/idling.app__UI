# selectionCalculations

- **`calculateEnhancedSelectionCoordinates`** — Screen rects for a logical range.
- **`calculateSelectionWithinToken`** — Partial pill selection.
- **`calculatePartialSelectionInToken`** — Sub-span inside one token.

Used by mouse drag and shift+arrow selection paths.
