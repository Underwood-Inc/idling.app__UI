# navigationUtils

Keyboard navigation helpers over `rawText` and token boundaries:

`smartCursorSnap`, `getWordBoundaries`, newline finders, `getLineBoundaries`, `navigateToLineStart/End`, `navigateUpLine/DownLine`, `findLastTextPosition`, `findLineEndPosition`.

Shared by `useKeyboardHandlers` and selection expansion.
