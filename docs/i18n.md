# Idling.app UI localization

English is the **source catalog** for site chrome strings managed with [typesafe-i18n](https://github.com/ivanhofer/typesafe-i18n).

## Supported locales

Canon manifest: [`src/i18n/supported-locales.json`](../src/i18n/supported-locales.json).  
Locale catalog Molecule: [`src/molecules/quotes/idlingLocaleCatalog.ts`](../src/molecules/quotes/idlingLocaleCatalog.ts).

## Commands

```bash
pnpm l10n:refresh          # quotes + UI via LibreTranslate (falls back to EN sync)
pnpm l10n:refresh:sync-en # offline: mirror EN into all locale files, then sync modules
pnpm i18n:translate       # UI chrome only
pnpm quotes:translate     # quote body text only
```

Machine translation uses self-hosted [LibreTranslate](https://github.com/LibreTranslate/LibreTranslate) (Mappy policy) on port **5000** (Docker stack).

## After catalog or `en.json` changes (agents)

Do **not** hand this off to the human. Use the **batch MT stack** (LibreTranslate on `:5000`, incremental ledger in `translation-meta.json`):

| Layer | Entry | What it does |
|-------|--------|----------------|
| **Full refresh (preferred)** | `pnpm l10n:refresh` | Quote shards (`translateAllStrings`, batch size 20) → UI strings (`translateWorkIndicesIncremental`, 5 keys/batch, concurrent slots on Windows) → `i18n:sync` → `i18n:generate`. Falls back to EN mirror if MT is down. |
| UI only | `pnpm i18n:translate` | Same incremental UI path as above (wrapper around `scripts/i18n-translate-locales.mjs`). |
| Quotes only | `pnpm quotes:translate` | **Incremental** quote bodies (`quote-translation-meta.json` + `translateWorkIndicesIncremental`, same batch/concurrency model as UI). |
| Offline | `pnpm l10n:refresh:sync-en` | Mirror EN into all locale files until MT is back. |

**Agent sequence after editing `i18n-en-catalog` or bootstrap data:**

1. `pnpm i18n:bootstrap-site`
2. `pnpm l10n:refresh` — one orchestrated pass; do **not** re-run ad-hoc `node scripts/…` duplicates unless debugging.

Re-fingerprint only when debugging meta drift: `node scripts/i18n-translate-locales.mjs --bootstrap-meta` (then `pnpm l10n:refresh` or `pnpm i18n:translate`).

## Runtime

Follow **Mappy site** only (typesafe-i18n): **sync English** on first paint (`idling-sync-en`); non-English UI chunks load only when the user picks a language or a **stored** preference is applied once after mount (not browser language). Never block the app shell on async locale fetch. No `subscribe*` / `notify*` bus.

- Provider: [`IdlingLocaleProvider`](../src/app/components/locale/IdlingLocaleProvider.tsx) — same shape as Mappy [`SiteLocaleContext`](https://github.com/Underwood-Inc/mappy-internal/blob/main/site/src/context/SiteLocaleContext.tsx)
- Seam: [`idling-i18n.ts`](../src/i18n/idling-i18n.ts) — same shape as Mappy [`mappy-i18n.ts`](https://github.com/Underwood-Inc/mappy-internal/blob/main/src/i18n/mappy-i18n.ts)
- Locale tests: [`idling-i18n-locale.test.ts`](../src/i18n/idling-i18n-locale.test.ts)
- User preference key: `idling-ui-locale` in `localStorage`

## Site catalog

English UI copy is consolidated in [`src/i18n/locales/en.json`](../src/i18n/locales/en.json), seeded from [`src/i18n-en-catalog/*.en.ts`](../src/i18n-en-catalog/) (errors, auth, admin, portfolio, profile, suite, tools, settings, meta, common, subscription, radio). Keep this folder **outside** `src/i18n/` so typesafe-i18n does not treat it as a locale.

**Server locale:** the footer picker mirrors `idling-ui-locale` to an HTTP cookie so RSC/metadata can call [`getServerLL()`](../src/i18n/idling-server-i18n.ts) ([`resolveServerIdlingLocale`](../src/molecules/quotes/resolveIdlingLocale.server.ts)).

**Client pattern:** `useIdlingLocale()` + [`resolveCatalogFromLl`](../src/molecules/i18n/resolveEnCatalog.ts), or area providers (`AdminCopyContext`, `SettingsCopyContext`, `ToolsCopyProvider`).

```bash
pnpm i18n:bootstrap-site   # rebuild en.json from source catalogs + showcase/suite data
pnpm i18n:generate && pnpm i18n:sync
pnpm i18n:translate          # LibreTranslate on :5000
```

## Covered surfaces

Site chrome, home hub, portfolio (showcase, **About**, **EcosystemDiagram**, **StatsDashboard**), Strixun suite landing + product detail tours, admin (tabs + subscriptions, users, custom alerts, **analytics**, **emojis**, **permissions**, **guest quotas**), **settings (full page)**, auth/error pages, **card-generator** (welcome, **wizard**, **generation form**, **advanced controls**), SVG converter shell, product catalog prose, product + profile metadata, **profile page UI** + **not-found**, **subscription** funnel page, **radio player** chrome (main bar, equalizer, track tip, resize handle), **mobile nav** menu aria, **BackButton**, localized private profile shell, common back-home links on marketing detail.

## Intentionally not catalogued

- API error bodies and dynamic subscription tier copy from `/api/subscription`
- User-generated content (bios, emoji names, analytics numbers)
- Mermaid diagram node labels inside ecosystem diagrams (technical graph content)
- Some admin modals, quota form field labels, permission list filters (deep CRUD UI)
- Packaged radio widget HTML in `src/widgets/radio-player/radio-player.ts` (legacy embed)
- Equalizer preset **match hint** paragraphs (dynamic preset names)
